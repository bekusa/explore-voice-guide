Kisahnya

Hirup udaranya sebelum Anda melihat. Ada sedikit aroma tajam di dalamnya, seperti kompor gas yang dibiarkan menyala terlalu lama. Kemudian Anda akan melihat nyala api. Nyala api itu berada di cekungan-cekungan di bebatuan yang gundul, beberapa seukuran lilin, yang lain setinggi orang. Nyala api itu tidak berkedip-kedip seperti api unggun. Nyala api itu condong dan menstabilkan diri, mendesis pelan. Bebatuan di sekitar setiap nyala api berwarna hitam dan hangat. Dekatkan tangan Anda dan Anda akan merasakan panasnya mendorong balik.

Lereng ini disebut Yanartaş dalam bahasa Turki, yang berarti batu yang terbakar. Letaknya di atas desa Çıralı, di sisi bawah gunung. Nyala api menyebar di atas teras kasar dari batu kapur yang pecah, bukan lubang api tunggal. Berjalanlah di antara nyala api dengan hati-hati. Beberapa lubang hanya berupa retakan kecil dengan lidah api biru di atasnya. Yang lain telah diperbesar selama bertahun-tahun oleh pengunjung yang membersihkan puing-puing dan batu.

Untuk sampai ke sini, Anda harus berjalan kaki, bukan berkendara. Jalan setapak berbatu menanjak dari tempat parkir melalui hutan pinus. Sebagian besar orang membutuhkan waktu dua puluh hingga tiga puluh menit untuk mendaki, dan lebih lama lagi untuk turun dalam gelap. Tangganya tidak rata dan licin karena dilewati ribuan kaki. Tidak ada penerangan di jalan setapak. Bawalah senter atau lampu kepala, dan bawalah air minum. Pegangan tangan ada di beberapa bagian dan tidak di bagian lain, jadi perhatikan langkah Anda di dekat jurang.

Yang terbakar di sini adalah gas yang merembes ke atas melalui batuan. Sebagian besar terdiri dari metana. Gas alam biasa berasal dari material organik yang terkubur, tetapi gas di lokasi ini tampaknya terbentuk secara berbeda. Para ahli geologi menghubungkannya dengan reaksi kimia antara air dan batuan kaya besi dari jauh di dalam bumi, yang telah terdorong ke permukaan di sepanjang pantai ini. Dengan kata lain, bahan bakar di sini dibuat oleh batuan itu sendiri, bukan oleh tumbuhan dan hewan purba.

Api tidak akan padam. Tutupi lubang ventilasi dengan batu atau jaket dan api akan berhenti, lalu muncul kembali saat Anda mengangkatnya. Trik itu populer di kalangan pengunjung, dan tidak berbahaya jika Anda cepat. Lubang ventilasi individu memang berubah. Beberapa memudar seiring waktu dan yang baru terbuka beberapa meter jauhnya. Area api secara keseluruhan telah menyala terus-menerus selama yang tercatat, dan itu sudah sangat lama.

Musim sangat berpengaruh. Di siang hari musim panas, api tampak redup dan mudah terlewatkan, dan jalan setapak terasa panas. Di musim gugur dan musim dingin, api tampak lebih kuat, sebagian karena udara lebih dingin dan kontrasnya lebih besar. Cuaca lembap juga tampaknya mempertajamnya. Hampir semua orang sepakat tentang satu hal — datanglah setelah gelap. Seluruh lereng berubah menjadi titik-titik cahaya oranye yang tersebar, dan Anda akan mendengar desisannya jauh lebih jelas.

Orang Yunani memiliki penjelasannya. Chimaera adalah monster dengan kepala singa, tubuh kambing, dan ekor ular, dan ia menyemburkan api. Homer menempatkannya di Lycia, wilayah kuno di pantai ini. Pahlawan Bellerophon membunuhnya saat menunggang kuda bersayap Pegasus, lalu mengusir makhluk itu ke dalam bumi. Legenda mengatakan bahwa api ini adalah monster yang masih bernapas di bawah tanah.

Orang-orang membangun di sini karena api. Di sekitar api, Anda dapat menemukan batu yang dipotong, garis dinding, dan sisa-sisa bangunan yang rendah. Para pengunjung kuno mengaitkan situs ini dengan Hephaistos, dewa api dan pengerjaan logam Yunani, dan sebuah tempat suci berdiri di lereng ini. Kemudian sebuah gereja Kristen dibangun di dekatnya, menggunakan kembali blok-blok batu yang lebih tua. Carilah batu persegi yang setengah terkubur di rerumputan, dan teras-teras datar yang jelas bukan alami.

Para pelaut sering dikatakan telah menggunakan api sebagai penanda, berlayar dengan berpedoman pada api tersebut di malam hari di sepanjang pantai dengan sedikit pelabuhan. Para penulis kuno menyebutkan api di gunung ini, meskipun detail tentang bagaimana api itu digunakan masih minim. Anggaplah kisah navigasi tersebut sebagai tradisi daripada catatan. Yang pasti adalah bahwa api ini dikenal, ditulis, dan dikunjungi pada zaman kuno, yang menjadikannya salah satu atraksi yang paling lama ada di Mediterania.

Keluarga-keluarga setempat telah lama menggembalakan hewan di lereng-lereng ini, dan ada warung teh kecil di jalan menuju puncak pada musimnya. Pengunjung terkadang menyeduh teh atau memanggang roti di atas lubang-lubang api. Jika Anda melakukannya, bawalah semuanya kembali. Situs ini berada di dalam area yang dilindungi, dan sampah di sekitar api akan merusaknya dengan cepat. Jaga anak-anak tetap dekat, dan jauhkan pakaian longgar dan rambut panjang dari lubang api. Nyala apinya kecil tetapi itu api sungguhan.

Poin-poin praktis untuk perjalanan pulang. Jalan turun lebih sulit daripada jalan naik, karena mata Anda sudah terbiasa dengan cahaya api. Beri waktu satu menit dalam kegelapan sebelum Anda mulai berjalan. Kenakan sepatu dengan sol yang tepat daripada sandal. Jika Anda datang dari Çıralı dengan berjalan kaki, jalan kembali ke pantai juga tidak berlampu. Banyak penginapan menyediakan layanan antar-jemput di malam hari, yang sebaiknya ditanyakan sebelum Anda berangkat.

Temukan batu datar, duduklah dan berhenti bergerak selama beberapa menit. Di atas Anda, gunung tampak hitam. Di bawah, melalui pepohonan pinus, Anda mungkin melihat cahaya dari desa dan, di baliknya, laut. Api di sekitar Anda menyala ketika kapal-kapal pertama datang di sepanjang pantai ini, dan api itu akan tetap menyala setelah bus Anda berangkat di pagi hari. Sangat sedikit tempat yang Anda kunjungi yang dapat dengan jujur mengklaim hal itu. Kemudian ambil senter Anda dan lanjutkan perjalanan.
